- **Durable provider sessions.** Prepared source for a session host that keeps provider sessions running while the daemon worker, supervisor or release restarts. Behind a setting file that is off by default, Claude and Codex agent sessions run in the host and the worker drives them through a proxy over a private, token-protected socket with bounded, validated frames, replay, stale-worker fencing and an audit log. Restarts leave hosted turns running, including ones reconnecting at that moment: the drain skips them, shutdown releases them and the next worker takes them over with an exact timeline.
