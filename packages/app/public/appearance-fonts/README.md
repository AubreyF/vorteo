# Appearance fonts

Barlow, Barlow Condensed, Manrope and Space Grotesk are bundled from Vorton's
`web/design/fonts` at revision `6e84901`. Their upstream OFL licenses are
included beside the font files. The stylesheet retains the source Unicode
ranges so browsers load only the subsets needed by the page.
The pinned stylesheet is excluded from automatic formatting to preserve its published bytes.

Keep published asset URLs immutable. When changing font bytes or declarations,
use new filenames and update the HTML stylesheet reference.
